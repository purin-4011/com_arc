วิธีอ่านตาราง · แต่ละแถว = ดึงบิตของตัวตั้งลงมา 1 บิต (จากซ้ายไปขวา) · ส่วนที่ได้ = เศษรอบก่อน ×2 + บิตที่ดึงลงมา · เทียบ = ส่วนที่ได้ กับตัวหาร · ถ้า ≥ ตัวหาร → q = 1 แล้วลบตัวหารออก ถ้าน้อยกว่า → q = 0 ไม่ลบ · เหลือ = ส่วนที่เหลือส่งต่อไปแถวถัดไป · อ่านผลหารจากคอลัมน์ q ตั้งแต่บนลงล่าง

กฎที่ต้องจำ: ตัวตั้ง = ผลหาร × ตัวหาร + เศษ และเศษต้องน้อยกว่าตัวหารเสมอ

2ชิ้นส่วน: ตัวลบ

เครื่องหารต้อง "ลบ" แล้วดูว่าผลติดลบไหม ตัวลบสร้างจาก full adder ตัวเดียวกับเครื่องคูณ วาดเป็นเกตจริง กดสลับ A, B, Cin ดูสายที่ติดไฟ (เส้นส้ม = 1)

ABCin
วิธีอ่านภาพ · A, B, Cin เข้าจากซ้าย ผ่านเกต XOR / AND / OR ไปออกที่ Sum (ผลบวก) กับ Cout (ตัวทดออก) · s1, c1, c2 = สัญญาณกลางทาง · เส้นส้ม = 1, เส้นเทา = 0

ลบด้วยตัวบวกได้: A − B = A + (กลับบิตของ B) + 1 จึงเอา full adder 5 ตัวมาต่อกัน ป้อน ~b (บิตของ B ที่กลับแล้ว) และตั้ง Cin = 1 ที่ตัวขวาสุด แล้วดูบิตซ้ายสุด (บิต 4): เป็น 1 = ผลติดลบ

    6สรุป

    1. หาร = เลื่อนซ้าย แล้ว ลบ ตัวหาร ถ้าลบได้เก็บผลและใส่ 1 ถ้าไม่ได้ ไม่เก็บผล (restore) และใส่ 0 ทำซ้ำ 32 รอบ
    2. ใช้ ALU 32 บิต (ต่อจาก full adder ที่กลับบิต B และ Cin = 1) และดูเครื่องหมายของผลลบ
    3. ผลอยู่ใน HI | LO: HI = เศษ, LO = ผลหาร (คำสั่ง div / divu แล้ว mfhi / mflo)
    4. เลขมีเครื่องหมาย: หารด้วยค่าสัมบูรณ์ ผลหารเป็นลบเมื่อเครื่องหมายต่างกัน เศษมีเครื่องหมายเดียวกับตัวตั้ง
    5. MIPS ไม่ตรวจหารด้วย 0 ซอฟต์แวร์ต้องตรวจเอง
