# วงจรคูณ 32 บิต: สร้างอย่างไร

สื่อการสอนแบบโต้ตอบ (HTML ไฟล์เดียว) อธิบายวงจรคูณ 32 บิตตั้งแต่ full adder จนถึงเครื่องคูณ
ตามสไลด์ "Integer Multiplication: Approach 2" วิชา 198322 สถาปัตยกรรมคอมพิวเตอร์

## มีอะไรในหน้านี้
- คูณบนกระดาษ 4 บิต (กดบิตเองได้)
- full adder ระดับเกต, ตัวบวก 4 บิต และ 32 บิต (ซูมดูเกตข้างในได้)
- แผนภาพเครื่องคูณ 32 บิต และ datapath 4 บิต (ตัวบวก → MUX → flip-flop)
- เดโมคำนวณ mult / multu ได้ HI และ LO พร้อมดูทีละรอบ
- เทียบ Approach 1 กับ 2 และ array multiplier 4×4
